## Findings

1. **High — A retention error prevents bots from running.** At [runtime/coordinator.mjs:1402](runtime/coordinator.mjs:1402), prompt pruning runs before the harness starts and outside the retention error handler. If an `UPDATE run_inputs` fails after the prompt insert succeeds, the run is marked failed without calling the harness; subsequent queued runs can fail the same way. **Smallest fix:** catch pruning errors separately and continue to the runner. **Test:** make the pruning update fail on the 51st prompt and assert that the runner is still called and the run succeeds.

2. **High — The code review checkpoint cannot run as configured.** [scripts/adversarial-review.mjs:59](scripts/adversarial-review.mjs:59) invokes `codex review --base main -` and sends the milestone prompt on stdin. That review command rejects a custom prompt, so code mode exits before writing its report. The dry run only prints the command and does not catch this. **Smallest fix:** use `codex exec` with the review prompt and an explicit base diff. **Test:** run code mode against the installed CLI and assert a report is produced.

3. **Medium — Audit events can outlive the stated 90-day retention period.** [runtime/coordinator.mjs:113](runtime/coordinator.mjs:113) calls `pruneEvents` only at startup. An app left open past the cutoff retains events until restart. **Smallest fix:** prune on a periodic timer or on event insertion. **Test:** advance an injected clock past 90 days without restarting and assert old events are removed.

4. **Medium — Three harness fixtures do not verify the claimed real-event compatibility.** [tests/fixtures/usage/README.md:10](tests/fixtures/usage/README.md:10) says the Codex fixture uses constructed event shapes and that Gemini was not captured; Cursor likewise has no capture provenance. Those parser tests can pass while the installed CLIs emit different fields. **Smallest fix:** replace them with sanitized captures from each CLI. **Test:** replay those captures through `runHarness` and check the stored usage.

**Must block merge:** findings 1 and 2.

This review covers `origin/main...HEAD`. The checkout also contains uncommitted edits, which I excluded. I could not run the CLI checkpoint in this read-only environment.
