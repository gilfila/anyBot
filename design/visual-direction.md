# anyBot visual direction

Source: installed Open Design CLI 0.22.2, `tools directions --id modern-minimal --json`, inspected 2026-09-19.

Use its quiet, precise, software-native direction: system typography, neutral foundations, hairline borders, restrained blue interaction color, and secondary employee colors. No gradients or decorative shadows. Shadows are reserved for dialogs. Local UI assets require no external font or image service.

The workspace uses a 240px navigation sidebar, a persistent 64px breadcrumb bar, a conversation-first main region, and an optional participant/context panel. Employees have stable name initials and harness color accents. Empty states are instructional, never fabricated conversations or fake completion statistics. The four role templates are explicitly templates until the owner creates an employee.

Primary blue: #3263db. Text: #20252d. Muted: #747c89. Border: #e7eaf0. Page: #fcfcfd. Surface: white. Illustrative employee colors: peach, blue, lavender, sage.

Trust acknowledgement belongs in employee creation; running jobs expose cancellation. The runtime state and execution location stay visible. The desktop app remains independent of Open Design at runtime.

Mobile carries the same direction into a focused conversation layout: four bottom tabs, full-screen chats, recipient chips, a sticky composer, clear host connectivity, and a bottom sheet for creating conversations. Connection credentials and host ownership are explicit. Layouts were inspected at 390 × 844 in Chromium and in a native Android emulator; screenshots are in docs/assets. No Superdesign was used.
